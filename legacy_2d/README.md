# 归途：最后一张地图

一款已实现、可以从序章通关到尾声的原创中文 2D 剧情探索游戏。陆寻带着妹妹留下的信出发，和四位旅伴走过七段航路。它围绕一只茶杯、一碗汤、一条围巾和被叫出的名字，讲述寻找、记住与告别。

这是设计为约 20–35 分钟的紧凑完整版本，实际时长随阅读和探索速度变化，并非最初设想的 25 小时大体量。没有外部素材下载、联网依赖或付费插件。

## 立即运行

- 在这台电脑上，双击 **开始游戏.cmd**。启动器使用桌面上已有的 Godot 4.7.2。
- 或在 Godot 4.3+ 导入本目录的 **project.godot**，按 **F5**。
- 主菜单点击「启程」，或按 Enter。已有进度可点「继续旅途」，或按 C。

默认窗口 1280 × 800，可缩放。中文使用系统字体（Windows 优先微软雅黑）；其他系统需要安装 Noto Sans CJK SC 等中文字体。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 快行 | Shift（消耗体力，放开恢复） |
| 交互、继续对白 | E / 空格 / 点击交互提示 |
| 地图 / 日记 / 伙伴 | M / J / P；也可点击右上按钮 |
| 日记翻页 | ↑ ↓ / ← → / 鼠标滚轮 |
| 暂停与音量 | Esc（再按一次返回） |
| 手动保存 | F5，或暂停菜单「保存航行记录」 |
| 机关 | ← → 选位，↑ / E 切换，Enter 确认；亦可点击 |

走近带金色标记的物件或人物，会出现 E 提示。左上角给出当前任务；屏幕边缘的金色「目标」指示当前目标方向；地图显示所有交互点。景物为绘画式地形，不设动作战斗。沙海的两条沙风带会减速、消耗体力，耗尽时将人推回营地；可以绕行，不会导致死亡或卡关。

每段航路都有一个飞艇营地。完成该章主要事件后，必须回营地交谈休息，才能从东北方的航路标启程。可以在此前多次聊天。重要事件、收集与章节切换会自动保存，退出前也可 F5 保存。

| 航路 | 可玩的探索与事件 |

| 无名沙海 | 绕过沙风、补水、重钉三枚风锚；沈知微留守拉住闸绳 |
| 黑海灯塔 | 点亮引航灯、还原三音旋律、兄妹重逢；闻笛陪伴失忆的姐姐 |

各地区使用独立配色和原创程序图形：森林、临水钟楼、雪峰星台、沙丘遗迹、夜海长堤、秋色原野、古树根系与海边旅店。含原创飞艇、角色、营火、粒子、光晕与程序生成氛围音。所有绘制与声音生成均在 game.gd 中完成；没有使用第三方版权图片或音乐。

## 存档

单槽进度存于 Godot 的 `user://homeward_v1.json`，音量单独存于 `user://preferences.cfg`。Windows 通常位于 `%APPDATA%/Godot/app_userdata/归途：最后一张地图/`。新旅途会覆盖当前单槽进度。只有对白推进完毕后，其结局回调才会记为完成；重新读档无需重做已经完成的机关。

## 验证与开发入口

核心文件：`project.godot`、`main.tscn`、`game.gd`。不需要额外场景或插件。

在本目录执行（PowerShell）：

```powershell
$engine = '<PROJECT_PATH>'
& $engine --headless --path . --editor --import --quit
& $engine --headless --path . -- --self-test
& $engine --path . --rendering-method gl_compatibility -- --capture
```

`--self-test` 在独立测试存档上运行完整路线，真实调用各章交互、距离选择、错误/正确机关解、出航条件、营地对白和结局回调；检查物理键 D 移动、M/Esc 输入与真实保存/继续。失败返回非零退出码。它会删掉自己的测试存档，**不会写入玩家存档**。

`--capture` 在实际 OpenGL 窗口渲染标题、对白、各地区和面板，输出 PNG 到 `tests/screenshots/` 后退出。它也使用独立临时存档。截图可以辅助检查字体与布局，不能替代真实游玩验收。

测试结果及范围见 `tests/RESULTS.md`。
